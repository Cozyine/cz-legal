Discord security bot for Roblox servers

Cozine watches your Discord server for Roblox exploiters and cheaters. When a flagged user joins, moderators get an instant alert in the channel you choose, with the evidence attached. Turn on the kick action and Cozine removes them automatically.

Auto-scan on join

Every new member is checked against the Cozine registry the moment they join. No manual lookups, no waiting.

Alerts or auto-kick

Choose alert-only so mods decide, or let Cozine kick flagged exploiters by itself.

Moderation panel

Look up any Discord user, check their record, and manage your server from the web panel.

How to add Cozine to your server

  1. Join the support server to get the bot invite.
  2. Add Cozine to your Discord server.
  3. Run the setup command to pick an alerts channel and threshold.

FAQ

What is Cozine bot?

Cozine is a Discord security bot that detects Roblox exploiters. When a flagged user joins your server, moderators get an alert and the bot can kick automatically.

How do I add Cozine to my Discord server?

Join the Cozine support server to get the invite, add it to your server, then run the setup command to enable auto-scan alerts.

Is Cozine free?

Cozine has a free tier with basic scanning and a Premium tier with detailed scan modes, API access, and a web panel.
